## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
A session can read every file but those under `/Users`, `/Volumes` and `/Library/Keychains`: that was left wide by decision when the profile became default deny, and deferred to this work. `read-system` is the narrower reading and has not been measured. Two questions are open: which reads a session needs, and whether `default` moves to `read-system` or stays as wide as today with `strict` as the choice. `offline` is `default` without the network. TASK-0002 (the agent-safehouse policy) may inform `strict`.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 `read-system` allows only reads that a failing probe needs; each allow names its probe, and the probes are kept as tests
- [ ] #2 `strict` and `offline` are run through the profile probes, each with its own expectations, as the current user and in a real session
- [ ] #3 Whether `default` moves to `read-system` is decided with Pat and recorded in the design doc with the reason
- [ ] #4 The design doc and README-SV2.md say what each of the three policies allows
