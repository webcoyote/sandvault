## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Most users will not write rules. `sv2 policy new NAME` asks questions and writes an ordinary policy file from a template, as `sv2 agent new` does for agents; what it writes can be edited by hand afterwards. What it asks is not decided. `--from POLICY` must write a list of includes and not a copy of the rules, or the copy would stop following the built-in policies of the helper at the next upgrade.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 What the wizard asks is decided with Pat and recorded in the design doc
- [ ] #2 `sv2 policy new NAME` writes a file that passes `policy check` and explains each line in a comment
- [ ] #3 `--from POLICY` writes includes, not rules
- [ ] #4 A name that a built-in policy has, or that exists, is refused
- [ ] #5 Without a terminal it writes the template and asks nothing
<!-- AC:END -->
