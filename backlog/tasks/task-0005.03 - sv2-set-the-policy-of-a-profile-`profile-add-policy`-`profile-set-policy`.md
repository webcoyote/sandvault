## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The way a policy gets from the host user to root. `sv2` sends the text and its name on stdin of a new helper verb; no path is passed. That stdin reaches the helper through sudo with `use_pty` set has not been measured and must be before the verb is built. A policy applies when it is set, not when its file is saved, so that no sandbox is widened by a save; and it applies only to sessions started afterwards, which matters because a tmux server outlives its session. `--ios` remains a switch of the session but only makes sense on a policy that includes `ios-simulator`.
<!-- SECTION:DESCRIPTION:END -->
